# Estética Automotiva

Landing page demonstrativa para o segmento de estética automotiva, desenvolvida com **HTML, CSS e JavaScript**, com animações, layout responsivo e simulação de orçamento.

O projeto apresenta uma vitrine digital para serviços de limpeza, proteção e acabamento de veículos, com identidade visual escura, detalhes em verde-água e composições gráficas abstratas.

> Projeto de portfólio. Não representa uma empresa real e não realiza atendimentos, envios de mensagens ou agendamentos.

## Recursos

- Layout responsivo para diferentes tamanhos de tela.
- Hero com tipografia de destaque e elementos gráficos em CSS.
- Catálogo de serviços de estética automotiva.
- Guia de cuidados com conteúdo ilustrativo.
- Apresentação das etapas de atendimento.
- Seleção de serviço e simulação local de orçamento.
- Menu mobile, perguntas frequentes e indicador de progresso da página.
- Animações de entrada e rolagem, respeitando a preferência por movimento reduzido.
- Recursos de acessibilidade, como link para pular ao conteúdo e controles de navegação identificados.
- Metadados de compartilhamento e dados estruturados de página demonstrativa.

## Serviços apresentados

- Polimento automotivo.
- Vitrificação.
- Higienização interna.
- Limpeza de motores.
- Lavagem avançada.
- Revitalização de faróis.
- Cristalização.

Os serviços são exemplos de conteúdo para uma landing page do segmento.

## Estrutura

- `index.html`: página principal.
- `css/style.css`: estilos e identidade visual.
- `css/responsive.css`: adaptações de layout.
- `css/animations.css`: estilos de animação.
- `js/config.js`: configuração do modo demonstrativo.
- `js/main.js`: navegação e interações.
- `js/animations.js`: animações com GSAP.
- `assets/logo/demo.svg`: símbolo geométrico demonstrativo.
- `robots.txt` e `sitemap.xml`: arquivos de apoio à publicação.

## Simulação de orçamento

Ao selecionar um serviço e clicar em **Testar orçamento**, a página exibe uma confirmação local. Nenhuma mensagem é enviada e nenhum dado é armazenado pelo formulário.
Não há telefone, endereço, perfil social ou integração de atendimento cadastrados.

## Publicação

O projeto pode ser hospedado em um serviço de arquivos estáticos. Mantenha `index.html` na raiz e preserve os caminhos das pastas `css`, `js` e `assets`.
Quando houver uma URL pública definida, configure os metadados de URL canônica e compartilhamento, preencha o `sitemap.xml` e adicione sua referência ao `robots.txt`.

## Personalização e uso

Para adaptar o modelo a um negócio, substitua os textos e a identidade visual, use imagens autorizadas e implemente os canais de atendimento com os dados do responsável.
O projeto utiliza elementos gráficos abstratos em vez de fotografias de estabelecimentos ou clientes. A identidade demonstrativa não implica exclusividade de marca. O uso comercial do código e do design depende das permissões aplicáveis; as bibliotecas externas seguem suas próprias licenças.
